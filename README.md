# EPP ZEW 2026 - In-Class Exercises 1

## Shell Navigation

1. Open a terminal.

1. Move to the home directory (MacOS / Linux) or user profile (Windows).

1. Create a new directory called "inclass_exercise_1".

1. Print the current working directory.

1. List the files and folders of your current directory.

1. Move into the newly created directory.

1. Print the current working directory.

1. List the files and folders of your current directory.

1. Go back up to the home directory (user profile).

1. Print the current working directory.

## Git

1. Change into the directory of the cloned repository.

1. List all the contents of the cloned repository

   > **Note:** You can use `"ls -a"` (on MacOS) or `"ls -hidden"` (on Windows) to see
   > all files, including hidden ones. You should be able to see the `.git` folder.

1. Check the current status of the repository to see if there are any changes.

1. Add the word "apple" to the file `a.txt` and "banana" to the file `b.txt`.

1. Check the status of the repository.

1. Display the commit history (log) of the repository.

1. Commit only the changes in file `a.txt`. Remember to use a sensible commit message.

1. Again, check the status of the repository.

1. Commit the remaining changes in file `b.txt`.

1. Again, check the status of the repository.

1. Check the commit history again to view your new and previous commits.

1. Create a new file called `c.txt` and add the word `coconut` to it.

1. Check the status of the repository.

1. Stage the new file for a commit.

1. Again, check the status of the repository.

1. Commit your changes.

1. Type `git push` in your shell in order to upload the changes to GitHub

1. Go to the GitHub page of your repository and check that the changes indeed have been
   uploaded and the files online look the same as the files on your computer.
